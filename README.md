# AudioCanvas

A browser-based, sound-reactive visualizer studio inspired by Winamp and MilkDrop.

> **M0 status:** The current studio contains the responsive application shell and a static visual preview. Audio analysis and reactive rendering are planned for later milestones.

## Development

Requirements: Node.js 22 and npm 10+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

Quality checks:

```bash
npm run check
npm run test:e2e
```
